Equation Solver Tool

Solve an equation, and see why.

Enter an equation, inequality or linear system. The solver classifies it, derives the answer line by line, checks it by substitution and plots it.

Examples
Operators+ - * / ^, with implied multiplication: 2x, 3(x+1), xy
Relations= < > <= >=. An expression without a relation is solved as “= 0”, or evaluated if it has no variable.
Functionssqrt cbrt abs or |x|, exp ln log (base 10), sin cos tan and their inverses
Constantspi (π) and e. Every other letter is a variable.
SystemsSeparate linear equations with a comma or semicolon: 2x + y = 5, x - y = 1
FormulasWith several variables, e.g. A = P(1 + rt), choose which one to solve for.
