Map the first step

Drag a stage from the library, or double-click anywhere on the map. Then pull a line from its edge to the next step.

How it works

Build the journey

Drag stages from the library into a phase column. A stage takes on the phase of the column it sits in, so moving it across columns moves it through the journey.

Connect stages

Hover a stage and drag from one of the dots on its edges onto another stage. Let go on empty space to create the next stage already connected.

Edit anything

Double-click a stage name, a connection, or a phase name to rename it. Everything else lives in the details panel on the right: channel, reach, feeling, pain points and opportunities.

Read the map

Select a stage to trace every path that leads to it and away from it. The track along the bottom shows how customers feel at each step.
