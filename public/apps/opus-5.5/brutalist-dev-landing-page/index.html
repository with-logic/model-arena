POST /v1/jobs

Enqueue a job

Send a task name, the URL that should run it and a payload. Rebar stores the job, calls your endpoint and retries with exponential backoff until it gets a 200.

Read the jobs guide 
import { Rebar } from "@rebar/sdk";

const rebar = new Rebar(process.env.REBAR_KEY);

const job = await rebar.jobs.create({
  task: "send-invoice",
  url: "https://acme.dev/jobs/invoice",
  payload: { customer: "cus_4821" },
  retry: { max: 5, backoff: "exponential" },
});

console.log(job.id); // job_01J9ZK4QX7

POST /v1/schedules

Schedule a cron

Standard cron syntax in any timezone. If a run is missed during a deploy or an outage on your side, Rebar runs it once you’re back instead of skipping it.

Read the schedules guide 
import { Rebar } from "@rebar/sdk";

const rebar = new Rebar(process.env.REBAR_KEY);

await rebar.schedules.create({
  cron: "0 9 * * MON",
  timezone: "Europe/Berlin",
  task: "weekly-digest",
  url: "https://acme.dev/jobs/digest",
  catchUp: true,
});
import os
from rebar import Rebar

rebar = Rebar(os.environ["REBAR_KEY"])

rebar.schedules.create(
    cron="0 9 * * MON",
    timezone="Europe/Berlin",
    task="weekly-digest",
    url="https://acme.dev/jobs/digest",
    catch_up=True,
)
curl -X POST https://api.rebar.dev/v1/schedules \
  -H "Authorization: Bearer $REBAR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "cron": "0 9 * * MON",
    "timezone": "Europe/Berlin",
    "task": "weekly-digest",
    "url": "https://acme.dev/jobs/digest",
    "catch_up": true
  }'
POST your-endpoint

Handle the callback

Rebar calls your HTTPS endpoint with a signed request. Check the signature, do the work and return 200. Anything else counts as a failure and triggers a retry.

Read the callbacks guide 
import { verifySignature } from "@rebar/sdk";

export async function POST(req) {
  const body = await req.text();
  const job = verifySignature(body, req.headers, process.env.REBAR_SECRET);

  await sendInvoice(job.payload.customer);
  return new Response("ok"); // 200 marks the job done
}
